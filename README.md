# Dazaet Galicia-Badillo - Personal Research Website

Live static website built for [dazaetgb.github.io](https://dazaetgb.github.io/) (*Crystals in Motion*).

## Updating Content

- **Profile, publications, awards, mentorship, or future Research Group mode:** edit `data/site-data.js`.
- **Add a new reading note / blog post from your computer:**
  1. Add a Markdown file inside `posts/` (see `posts/2026-11-25-terence-tao-mathematics-ai.md`).
  2. Run `python build_posts.py`.
  3. Commit and push to `main` (`git add -A && git commit -m "Update site" && git push`).
